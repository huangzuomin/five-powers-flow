| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

Security and boundary isolation are top priorities for Five-Powers-Flow. If you discover a vulnerability—especially related to:
- Sandbox escape or file privilege escalation between isolated worktrees;
- Agent impersonation or unauthorized permission escalation (e.g., bypass of Human Sovereign merge approval);
- Credential leak or state injection via unverified coordination cards;

**Please DO NOT create a public GitHub issue.**

Instead, please send an email to the project maintainer or submit a Private Vulnerability Advisory via GitHub Security Advisory. We will acknowledge receipt within 48 hours and work with you to patch and disclose the issue responsibly.
